# Prompt Frontend

## Objetivo
Construir un panel en FilamentPHP con UX clara para operar rifas, pagos, clientes, boletos, conversaciones y configuracion de empresa.

## Debe Incluir
- Dashboard con metricas clave.
- Recursos para rifas, compras, pagos y boletos.
- Modulo de configuracion de empresa y branding.
- Filtros rapidos y estados visibles.
- Historial conversacional y seguimiento basico.
- Modulo administrable para FAQ y textos fijos.
- Recursos Filament alineados con [23-recursos-filament.md](file:///Users/macbookpro/Documents/DESARROLLO/Rifax/23-recursos-filament.md).

## Restricciones
- Priorizar productividad operativa.
- Evitar interfaces recargadas.
- Mantener consistencia visual.
- Si se requiere tooling Node, usar `pnpm` como package manager.

## Criterios de Aceptacion
- Operaciones criticas accesibles en pocos clics.
- Mensajes de estado claros.
- Formularios con validacion y ayudas utiles.
- Acciones de negocio sensibles encapsuladas en acciones controladas, no en edicion libre de campos.
